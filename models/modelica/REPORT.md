## 해석과 한계

두 모델은 서로 다른 풀이 방식으로 같은 방정식을 풀었다. 이 결과는 연결·단위·절대압·손실 계수와 계산 구현의 일관성을 검증한다. 두 모델이 공유하는 합성 펌프 곡선, 균일 밀도·고정 Darcy 계수, 정상 상태·단상 가정은 실제 설비 데이터로 독립 검증해야 한다. 기계적 수지는 열수지나 온도 검증을 포함하지 않는다. 역류, 캐비테이션, 점도의 영향, 압축성·과도응답, 증류·제품 조성, 마모·수리 시계열은 이번 비교 범위 밖이다.

### 재사용 근거와 범위

- 같은 `PlantHydraulics.Circuit`(결합)·`SingleCircuit`(단일) 모델을 플랜트별 설정 입력으로 **각각 실제 실행**했다. CDU 결과를 다른 플랜트 결과로 쓰지 않았다. 재사용 근거: 다섯 결합 회로가 같은 위상(입력 펌프 → 헤더 → 다른 등가 분기 | 배관 → 밸브 → 후속 스트레이너 → 후속 펌프 → 토출 배관)이고 차이는 설정값뿐이다.
- 증기압·NPSHr·유체 온도는 합성 값이다(플랜트 설정 머리 주석·`scripts/calibrate_physics.py`). 고온 펌프의 유체 온도는 흡입·취급 유체 온도 태그 μ, 나머지는 합성 설계 선택.
- 미검증: 기포 동역학·침식·캐비테이션 진동·과도응답·열수지·혼상, 직렬 등가 회로의 중간 드럼 부재, 실제 설비 곡선. 정상 상태 비교만으로 이를 검증했다고 보지 않는다.
- 이 단계에서 생성기·고장 엔진·수집기 API 동작은 바꾸지 않았다(회로 해에 캐비테이션 항이 추가됐을 뿐, 경로·계약 동일). 시뮬레이터 pytest 405 통과.
